# TerminalHire

Ask the candidate. Not just the resume. Mrudul's AI Representative

TerminalHire is an AI-powered recruiter-facing portfolio assistant that allows interviewers and hiring managers to interact with a candidate through a conversational interface.

## Tech Stack

- React + Vite + Tailwind CSS
- FastAPI
- Groq LLM API
- JSON-based candidate memory

## Features

- Streaming AI chat
- Candidate memory
- JD matching
- Resume upload
- Interview question generation
- Export chat as PDF
